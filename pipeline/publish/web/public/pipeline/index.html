The pipeline, step by step

How a state's law becomes structured data

The pipeline runs the same five steps for every occupation, one state at a time. It starts with the state's full set of statutes and ends with a row of data on the website. Three of the steps are free. Two of them use an AI model, which costs a few cents per state.

The full book of state statutes

Everything the state publishes online — thousands of chapters, only a few of which touch this occupation.

Clean

Strip out web-page boilerplate — menus, footers, formatting — and normalize the raw legal text.

The two AI steps

3

Keep only what's relevant

paid · ~$0.05 / state
Trim

An AI model reads the cleaned law and drops the parts that aren't about this occupation.

4

Pull out the tags

paid · ~$0.15 / state
Extract

An AI model reads the trimmed law into structured fields and tags — scope of practice, disciplinary grounds, education, and more.

5

Push to the website

free
Publish

Package the finished records into the payload the interactive site serves — one row per occupation, per state.
