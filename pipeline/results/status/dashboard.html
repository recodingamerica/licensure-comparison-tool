Licensing pipeline — pick occupations to process

Each occupation's law is fetched and stored in this repo. Tick the ones you want structured data for, then run the commands at the bottom. Only trim and extract cost money; clean and publish are free.

What does each step do?
clean (free)tidies the fetched statute text (de-duplicates, normalizes)
trim (~$0.05/state, claude-haiku-4-5-20251001)an AI keeps only the sections relevant to this occupation
extract (~$0.15/state, claude-sonnet-4-6)an AI turns that law into the structured data (the deliverable)
publish (free)builds the web payload so the occupation shows on the site

Trim/extract prices are for the model in use today — they move if the model changes. `run.py` always prints the exact estimate (and the model) before spending anything.
